# Python-preparation
Documenting my Python learning journey through organized notes, practical exercises, and interview-focused coding practice.

## 🐍 Python Preparation Series: Weeks 1-3 Overview

This repository contains a structured, day-by-day Python learning series designed to take you from fundamental syntax to advanced functional programming and file handling. Below is a breakdown of what is covered in the first three weeks of the curriculum:

### 📘 Week 1: Python Fundamentals
This week establishes the core building blocks of Python programming.
* **Day 01 - 03 (Basics & Control Flow):** Introduction to variables, escape sequences, Unicode, type casting, operators, and conditional (`if/else`) statements.
* **Day 04 - 05 (Strings):** Deep dive into string manipulation, indexing, slicing, and common string methods through programs like palindrome checkers and word counters.
* **Day 06 - 07 (Basic Data Structures):** Hands-on practice with Python's core collections: Lists, Tuples, and Dictionaries, including iteration and built-in methods.

### 📗 Week 2: Problem Solving, Loops, and Functions
This week shifts the focus toward logical problem-solving, algorithm efficiency, and code reusability.
* **Day 08 (Advanced Collections):** Exploring Sets, set operations (union, intersection, difference), and navigating nested lists and dictionaries.
* **Day 09 - 11 (Iteration & Patterns):** Mastering `for` and `while` loops through number-based programming (Factorials, Fibonacci series, Armstrong numbers) and utilizing nested loops for pyramid pattern printing.
* **Day 12 - 13 (Functions & Searching):** Writing user-defined functions, understanding jump statements (`break`, `continue`, `pass`), working with complex arguments (`*args`, `**kwargs`), and implementing Linear and Binary Search algorithms.

### 📙 Week 3: Functional Programming and File Handling
This week introduces advanced, "Pythonic" techniques to write cleaner, more efficient code and interact with the operating system.
* **Day 14 - 15 (Functional Programming):** Utilizing concise `lambda` functions, processing collections dynamically with `map()` and `filter()`, and writing elegant List Comprehensions.
* **Day 16 (Modules & File I/O):** Understanding how to import and structure modules/packages, and mastering file handling (reading, writing, and appending text files) using the safe `with open()` context manager.
